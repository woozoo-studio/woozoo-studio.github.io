01 / AMR · 관제 연동

관제 위치 발행 분리

문제
기존 관제는 amcl_pose 메시지를 받을 때 위치를 갱신했습니다. 관제용 위치 발행을 AMCL 메시지 수신과 분리할 필요가 있었습니다.
해결
TF의 map → base_footprint 변환에서 로봇 위치를 읽어 관제용 토픽으로 발행하는 별도 ROS2 노드를 작성했습니다.
결과
AMCL·오도메트리 기반 TF를 활용하면서 관제용 위치 전달을 별도 토픽으로 구성하고, FMS의 지도 표시에 연동했습니다.
02 / 모바일 회수 로봇

내부 Flash에 티칭 저장

문제
전원이 꺼져도 티칭 데이터를 유지해야 했습니다. EEPROM을 추가하는 대신 STM32 보드 내부의 Flash를 활용할 수 있는지 검토했습니다.
해결
마지막 128KiB(Sector 7)를 데이터용으로 확보하고, 링커에서 펌웨어 영역을 384KiB로 제한해 두 영역이 겹치지 않도록 구성했습니다.
결과
RAM에 모은 데이터를 Flash에 기록·검증하고 부팅 시 불러오도록 구현했습니다. 별도 EEPROM 없이 12개 시퀀스와 시퀀스당 최대 30 Waypoint를 저장합니다.
