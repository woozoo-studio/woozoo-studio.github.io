# Robotics Software Portfolio

로봇 SW · 자율주행 · 로봇 SI · 산업 자동화 분야를 위한 개인 포트폴리오 웹사이트입니다.

## Live Portfolio

https://woozoo-studio.github.io/

## Overview

프로젝트에서 직접 담당한 역할과 구현 과정, 문제 해결 및 검증 결과를 중심으로 정리했습니다.

주요 프로젝트:

- **Logistics AMR** — ROS 2 기반 AMR 자율주행 및 경로 관리
- **Mobile Retrieval Robot** — 모바일 플랫폼과 6축 로봇팔 통합 제어
- **PLC MPS Automation** — PLC 기반 공정 자동화 및 비상정지/복귀
- **Vision Patrol Robot** — STM32 주행 제어 및 YOLO Pose 기반 비전

## Tech Stack
